# Codex Companion 1.1.0-beta.1

An independently maintained fork of OpenAI's Codex plugin, adding native Codex workers in Claude Code. Apache-2.0; not affiliated with or endorsed by OpenAI or Anthropic.

## Changes

- Native Agent workers execute the actual Codex runtime for implementation and debugging.
- Live activity shows task, model, effort, progress, and exact-worker cancellation.
- Automatic completion feedback and full report retrieval by Claude.
- Topic follow-ups and adversarial re-reviews continue their original worker and Codex thread.
- Agents-view handoffs retain identity; completed idle conversations archive recoverably.
- One directly installable marketplace package with independent branding, deterministic generation, and ZIP/checksum assets.

## Install

Finish delegated work and close Claude before replacing another Codex plugin. Uninstall the official or earlier trial plugin with `--keep-data`, then:

```bash
claude plugin marketplace add HuabeiYou/codex-plugin-cc
claude plugin install codex@codex-companion --scope user
```

Start a new session and run `/codex:setup`. Existing `/codex:*` commands remain. No source build is needed. See the [README](../../README.md) for full instructions and rollback.

The standalone ZIP contains a marketplace at its root. Extract it into a permanent directory, then add that directory with `claude plugin marketplace add <directory>` and install `codex@codex-companion`. Verify the archive with the accompanying SHA-256 file.
